# 성남시 생활폐기물 자료 검토

확인일: 2026-11-08. 이 기록은 수동 검토한 자료·사실정보의 출처와 미확정 항목을 추적하기 위한 문서입니다. 최신 규칙의 포괄적 검증이나 문서 전체의 자유로운 재사용을 뜻하지 않습니다.

## 확인 방법과 원본

성남시 [생활 쓰레기 분리배출 안내](https://recycle.seongnam.go.kr/platforminfo/trash)의 공개 다운로드 버튼이 연결하는 PDF 3개를 임시 폴더에서 검토했습니다. 원본·페이지 이미지는 저장소나 `public`에 넣지 않았습니다. 프로젝트 의존성을 바꾸지 않고 임시 폴더의 PDF.js로 텍스트 추출과 이미지 렌더링을 수행했습니다.

## 이용조건과 생성 제한

안내책자 **PDF 3쪽**은 공공누리 제4유형(출처표시·상업적 이용금지·변경금지)을 명시하며, 사진·일러스트·삽화의 개별 이용도 제한합니다. 포털의 [저작권 안내](https://recycle.seongnam.go.kr/guide/copyright)는 별도 표시가 없는 저작물은 담당부서와 협의하도록 안내합니다.

이번 구현은 출처를 표시한 사실정보 정리와 원문 연결입니다. 원문 본문·이미지·PDF 전체를 LLM 입력으로 보내지 않고, `generationAllowed: false`를 유지합니다. 제4유형 자료를 자유로운 학습·요약·상업적 재사용에 승인된 자료로 취급하지 않습니다. 외부 공개·상업화 또는 문서 기반 생성 답변으로 확대하기 전에는 사용하려는 범위의 이용조건을 확인해야 합니다. 모델 호출 없이 정해진 자료를 직접 표시하는 것이며 파인튜닝·임베딩·AWS Knowledge Base 생성은 수행하지 않았습니다.

## 구현과 검증

- `lib/waste-guide.ts`: 출처 링크, PDF 쪽수, 5개 폐기물 분류, 주택 유형, 50개 행정동 업체 매핑. 문서 발행일이 불명확해 확인일만 기록하며 `dataAsOf`를 꾸며 넣지 않습니다.
- `components/WasteGuide.tsx`: 동네 정보의 생활폐기물 카드에서 유형·품목 선택, 배출/수거시간 구분, 문서 차이, 해당 동 업체와 공식 웹 안내를 표시합니다. 사용자 요청으로 PDF 다운로드 버튼은 제거했으며 쪽수는 내부 자료에 보존합니다.
- 검색 결과는 같은 사실정보를 `formatWasteAnswer`로 문장 형태로 구성하고 `answer` 필드에 담아 표시합니다. 카드 선택 UI를 검색 답변에 복제하지 않으며 공식 배출 안내 웹 링크를 출처로 제공합니다. 새 자료의 LLM 생성 제한은 그대로 유지합니다.
- 기존 적격 근거 기반 LLM 경로는 유지하며, 새 기본 안내는 `waste_results`로 직접 반환합니다. 테스트 fixture의 승인 근거를 덮어쓰지 않습니다. 실제 LLM을 호출하거나 새 자료를 기존 승인 레지스트리에 자동 편입하지 않습니다.
- 담당 업체의 기본 행정동 목록은 공식 센터 CSV의 50개 행정동과 각각 한 번씩 일치하는지 테스트합니다. 법정동 주소로 관할을 추정하지 않습니다.
- 실제 화면·휴대폰·링크 클릭 동작은 별도 수동 검증 대상이며, 기존 현재 위치 문제는 계속 보류합니다.
